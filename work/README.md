# work/ フォルダ — チーム作業ファイル置き場

このフォルダはチームメンバーが案件ごとに作業中のファイルを保存・共有する場所です。

---

## ファイル命名規則

```
[案件略称]_[YYYYMMDD]_v[バージョン番号]_[担当者イニシャル].html
```

### 例

| ファイル名 | 意味 |
|---|---|
| `ABC社_20250711_v1_KS.html` | ABC社案件、2025-07-11作成、バージョン1、KS作成 |
| `ABC社_20250714_v2_MT.html` | 上記をMTが修正したバージョン2 |
| `ABC社_20250715_v3_KS.html` | さらにKSが修正したバージョン3 |

---

## 作業フロー

1. `quotation-tool.html`（テンプレート）を GitHub 上で Raw → 保存して開く
2. 内容を入力・編集し、**💾 保存** でローカルに `.html` ファイルをダウンロード
3. 命名規則に従ってファイル名を変更する
4. このフォルダ（`work/`）に GitHub 上でアップロード
5. `WORK_LOG.md` に変更内容を追記する
6. 次の担当者はこのフォルダの最新ファイルを取得して作業を継続する

---

## 注意事項

- **お客様の実名・機密情報が含まれる場合は、このリポジトリには保存しないでください**
- サンプル・社内レビュー用・匿名化済みファイルのみ保存してください
- 最終版は `releases/` フォルダに移動して管理者が管理します
