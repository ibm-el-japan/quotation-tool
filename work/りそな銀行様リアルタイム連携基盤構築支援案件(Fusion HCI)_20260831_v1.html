本サービスは、お客様の業務を支援する作業として提供されるものです。

作業の対応時間は、平日標準勤務時間（9:00～18:00）です。

作業場所はりそな銀行様の大阪府千里、および栃木県の拠点を想定しています。
Fusion HCI導入・構築作業、単体テストはりそな銀行様の大阪府千里で実施し、単体テストが終了したものをりそな銀行様の栃木県の拠点へ移送する想定です。

Fusion HCI、バックアップ、DNSサーバおよびリポジトリサーバの現地作業は、りそな銀行様の大阪府千里拠点への移設作業までを範囲とし、その後に作業が発生する場合は、りそな銀行様の栃木県拠点にて実施する想定です。
お客様にプロジェクトの全体管理をお願いいたします。

構築およびテストの作業は、2人以上での作業となります。

👥 GitHub コラボレーター設定・権限管理

▼

同じ部署のチームメンバーがリポジトリにアクセスし、ファイルを共同編集するための設定手順です。

ロール権限用途
Admin（管理者）リポジトリの全設定・削除・コラボレーター管理・ブランチ保護フォーマット管理者（ibmkevin 等）
Write（書き込み）ファイルの作成・編集・コミット・プルリクエスト作成チームメンバー（担当SE等）
Read（読み取り）ファイルの閲覧・ダウンロードのみ参照のみのメンバー

コラボレーター追加手順

  1. GitHub の Settings → Collaborators and teams を開く
  2. 「Add people」または「Add teams」をクリック
  3. 追加したいメンバーの GitHub ユーザー名またはメールアドレスを入力
  4. ロールを Write（通常メンバー）または Admin（管理者）から選択
  5. 「Add [username] to this repository」をクリック → 招待メールが送信される
  6. 招待されたメンバーがメール内のリンクを承認するとアクセス可能になる

ファイル共同編集フロー（GitHub連携機能使用）

  1. チームポータル から「ツールを開く」をクリック（URLコピー不要）
  2. データを入力後、「☁️ GitHubへ保存」ボタン → 担当者名・PAT・コメントを入力 → 保存
  3. 別のメンバーは「📂 GitHubから開く」ボタン → 一覧からファイルを選択 → 編集継続
  4. 変更履歴は GitHub コミット履歴 で「誰が・いつ・何を変更したか」を確認可能
