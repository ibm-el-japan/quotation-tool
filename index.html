🚀 ツールを開く

📋 見積もり作成ツールを開く

クリックするとブラウザ上でそのまま動作します。インストール不要。

📖 使い方（基本フロー）

① ツールを開く
→
② 情報を入力
→
③ 💾 保存
→
④ work/ にアップ
→
⑤ WORK_LOG 記入
1
上の「ツールを開く」ボタンをクリック
ブラウザ上でそのまま動作します
2
各タブに情報を入力する
基本情報 → チェックシート → 工数（移動回数・宿泊数含む）→ 交通費等
3
「💾 保存」ボタンでファイルをダウンロード
命名規則に従ってリネーム: 案件名_YYYYMMDD_v1_イニシャル.html
4
GitHub の work/ フォルダにアップロード
work/ フォルダを開く → Add file → Upload files → Commit
5
WORK_LOG.md に変更内容を記入
WORK_LOG.md を開く → ✏️ Edit → 変更内容を追記 → Commit

🔄 他のメンバーのファイルを引き継いで編集する

1
work/ フォルダで最新ファイルを確認する
work/ フォルダを開く → 最新のファイルをクリック
2
Raw ボタン → ファイルを保存 → ブラウザで開く
前回の入力内容がすべて復元された状態で開きます
3
修正後、「💾 保存」→ バージョン番号を +1 してリネーム
例: 案件名_20250714_v2_MT.html
4
work/ にアップロード → WORK_LOG.md に変更内容を追記

📝 ファイル命名規則

[案件略称]_[YYYYMMDD]_v[番号]_[担当者イニシャル].html

要素内容例
案件略称お客様名や案件の略称ABC社
YYYYMMDDそのバージョンを作成した日付20250711
v[番号]修正するたびに +1v1, v2, v3
担当者イニシャル作成した人のイニシャルKS, MT

📄 変更履歴の確認方法

WORK_LOG 誰が・いつ・何を変更したかの詳細記録
📄 WORK_LOG.md を開く →
各バージョンの担当者・ベースファイル・変更内容・備考が一覧で確認できます。
Git 履歴 ファイルのアップロード・更新の時系列記録
🕒 コミット履歴を開く →
誰がいつどのファイルをアップしたか確認できます。

🔐 権限・ロール

👤 一般ユーザー（デフォルト）

  • お客様名・案件名の入力
  • チェックシート・工数・交通費の入力
  • お客様提出用ドキュメントの出力
  • 案件ファイルの保存・読み込み
  • work/ へのアップロード・WORK_LOG記入

🔑 管理者モード（ツール内）

  • 上記すべて＋
  • Labor単価の変更
  • Contingency・GP 率の変更
  • フォーマット変更・GitHub管理

管理者モードへのログイン: ツール右上の 🔑 ボタン → パスワード入力
