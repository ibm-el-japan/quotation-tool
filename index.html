🚀 ツールを開く

📋 見積もり作成ツールを開く

クリックするとブラウザ上でそのまま動作します。インストール不要。

🔄 チーム共同編集フロー

① ツールを開く
→
② 情報を入力
→
③ GitHub へ保存
→
④ 次の担当者が開く
→
⑤ 差分を確認・編集
→
⑥ 出力・提出
🔍 変更差分の自動表示：ファイルを開くと、前バージョンからの変更内容（基本情報・工数・交通費・チェックシート）がシートごとにモーダルで自動表示されます。
1
上の「ツールを開く」ボタンをクリック
URLのコピーや直接入力は不要です
2
各タブに情報を入力する
基本情報 → チェックシート → 工数 → 交通費等
3
「💾 保存 → GitHubへ」ボタンをクリック
ファイルをダウンロードしてから work/ フォルダ にアップロードしてください
4
他のメンバーは「📂 GitHubから開く」ボタンをクリック
PAT を入力すると work/ のファイル一覧が表示 → クリックで即読み込み
5
ファイルを開くと差分モーダルが自動表示
前バージョンからの変更点をシートごとに確認してから編集開始
6
編集後、再度保存・アップロード。v番号を +1 してリネーム
例: ABC社_20250901_v2_MT.html

📝 ファイル命名規則

[案件略称]_[YYYYMMDD]_v[番号]_[担当者イニシャル].html

要素内容例
案件略称お客様名や案件の略称ABC社
YYYYMMDDそのバージョンを作成した日付20250901
v[番号]修正するたびに +1v1, v2, v3
担当者イニシャル作成した人のイニシャルKS, MT

🔐 権限・ロール

👤 一般ユーザー（デフォルト）

  • お客様名・案件名の入力
  • Labor単価・Contingency・GP 率の変更
  • チェックシート・工数・交通費の入力
  • お客様提出用ドキュメントの出力（印刷・PDF）
  • 案件ファイルの保存・読み込み（ローカル・GitHub）

GitHub アカウントの登録申請はツール内「📋 バージョン情報」タブの「🙋 GitHub アカウント登録申請」セクションから行えます。

📄 変更履歴の確認方法

GitHub Commits 誰が・いつ・何を変更したかの自動記録
🕒 コミット履歴を開く →
ファイルを保存・アップロードすると変更履歴として自動的に記録されます。
差分モーダル ファイルを開いた際に自動表示
前バージョンからの変更内容（追加・変更・削除）をシートごとに色分けで確認できます。
