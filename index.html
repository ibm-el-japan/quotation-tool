📋 見積もり作成ツールを開く

クリックするとブラウザ上でそのまま動作します。インストール不要。

☁️ GitHub連携での保存・共有フロー（v1.2.0〜）

GitHub Personal Access Token (PAT) を使ってブラウザから直接 work/ フォルダに保存できます。
PAT はセッション中のみ保持（ページを閉じると削除）。取得方法: GitHub → Settings → Developer settings → Personal access tokens → repo スコープで作成。
① ツールを開く
→
② 情報を入力
→
③ ☁️ GitHubへ保存
→
④ 他メンバーが開く
→
⑤ 編集・再保存
1
上の「ツールを開く」ボタンをクリック
URLのコピーや直接入力は不要です
2
各タブに情報を入力する
基本情報 → チェックシート → 工数 → 交通費等
3
「☁️ GitHubへ保存」ボタンをクリック
担当者名（イニシャル）・PAT・変更コメントを入力 → 保存。
コミットメッセージとして「誰が・何を変更したか」が自動記録されます
4
他のメンバーは「📂 GitHubから開く」ボタンをクリック
work/ フォルダのファイル一覧が表示 → クリックで読み込み
5
編集後、再度「☁️ GitHubへ保存」で上書き保存
変更コメントを入力することで何を変更したかが履歴に残ります

📖 ローカル保存フロー（PAT不要）

1
「💾 ローカル保存」でファイルをダウンロード
命名規則に従ってリネーム: 案件名_YYYYMMDD_v1_イニシャル.html
2
GitHub の work/ フォルダにアップロード（手動）
work/ フォルダを開く → Add file → Upload files → Commit
3
WORK_LOG.md に変更内容を記入
WORK_LOG.md を開く → ✏️ Edit → 変更内容を追記 → Commit

🔄 他のメンバーのファイルを引き継いで編集する

A
【GitHub連携】ツール内「📂 GitHubから開く」→ 一覧からファイルを選択
PAT が必要。クリックするだけで内容が復元されます
B
【手動】work/ フォルダ → ファイルをクリック → Raw → ブラウザで開く
前回の入力内容がすべて復元された状態で開きます
3
修正後、「☁️ GitHubへ保存」または「💾 ローカル保存」→ v番号を +1 してリネーム
例: 案件名_20250831_v2_MT.html

📝 ファイル命名規則

[案件略称]_[YYYYMMDD]_v[番号]_[担当者イニシャル].html

要素内容例
案件略称お客様名や案件の略称ABC社
YYYYMMDDそのバージョンを作成した日付20250831
v[番号]修正するたびに +1v1, v2, v3
担当者イニシャル作成した人のイニシャルKS, MT
